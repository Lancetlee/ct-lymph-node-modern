# 分站、常规 CT 征象与标签

核查日期：2026-11-12。使用 IASLC 肺癌淋巴结地图及 TNM 第 9 版语境。此地图不能自动替代食管癌、乳腺癌或淋巴瘤等疾病自己的分期体系。站位是解剖分类；影像可疑、组织学转移和患者 N 分期是不同输出。

## 一、分站的解剖核对

下表是训练重点，不能替代完整图谱。必须结合连续切片和冠/矢状重建；解剖标志受肿瘤扭曲或缺层时保留不确定。[IASLC 官方第 3 版手册](https://www.iaslc.org/research-education/publications-resources-guidelines/staging-manual-thoracic-oncology-3rd-edition)、[ESTS 解剖定义表 2](https://www.ests.org/_userfiles/pages/files/revised_ests_guidelines.pdf)

| 站位/边界 | 用于训练的解剖核对 |
|---|---|
| 1R/1L，低颈/锁骨上/胸骨切迹 | 从环状软骨下缘到两侧锁骨、中央胸骨柄上缘；左右按气管中线。二维示意线不能替代这些立体边界。 |
| 2R/2L，上气管旁 | 左右分界用气管左侧壁；2R 与 4R 的界限是左头臂静脉尾缘与气管交会处，不能误记为头臂动脉；2L 与 4L 以主动脉弓上缘分开。 |
| 3A/3P | 3A 为血管前，3P 为气管后，下达隆突；不是把一切“血管后”或隆突以下食管旁区域都叫 3P。 |
| 4R/4L，下气管旁 | 左右仍以气管左侧壁分界。4R 下界为奇静脉下缘；4L 下界为左主肺动脉上缘。不可把这条左右规则推广到 1R/1L。 |
| 4L 与 5 | 4L 在动脉韧带内侧，5 在其外侧；5 为主动脉下/主动脉肺动脉窗，上下界为主动脉弓下缘、左主肺动脉上缘。标志不清时需复核。 |
| 6，主动脉旁 | 升主动脉及主动脉弓前外侧，位于弓上缘切线与弓下缘之间；不能与 5 混为“主动脉旁的一圈”。 |
| 7，隆突下 | 上界为隆突；下界左侧为左下叶支气管上缘，右侧为中间支气管下缘。不是所有隆突以下结节都属 7。 |
| 8，食管旁 | 排除 7 的食管旁区域，向下到膈；需要结合其头尾位置。 |
| 9，肺韧带 | 在肺韧带内，从下肺静脉至膈。只因靠近食管或下肺静脉不足以定 9。 |
| 10，肺门 | 紧邻主支气管和肺门血管；上界右为奇静脉下缘，左为左主肺动脉上缘。注意与 4 及 7 的关系。 |
| 11，叶间 | 在叶支气管起始之间；右侧 11Rs 位于上叶支气管与中间支气管间，11Ri 位于中叶与下叶支气管间。 |
| 12/13/14 | 分别沿叶/段/亚段支气管；沿对应分支连续追踪，不能只按单层位置推断。 |

正式地图原始出处：Rusch 等，JTO 2009，[DOI 10.1097/JTO.0b013e3181a0d82e](https://doi.org/10.1097/JTO.0b013e3181a0d82e)。原文访问受限，详细边界在本次通过官方手册索引及 ESTS 表 2 对照核查；未来使用时应打开本机构采用版本的图谱。

## 二、常规征象：记录而不代替病理

| 观察项 | 记录方式与解释边界 |
|---|---|
| 大小 | 留存长短径、平面、层面及既往变化。短径 10 mm 是常用增大/进一步评估界值；小于它不等于无转移，大于它也不等于转移。 |
| 圆/饱满、长短径关系 | 记录为形态观察提示；不是恶性专属特征，也不等于已经计算了球形度。 |
| 边缘、融合、周围脂肪/组织 | 分开记录；融合团块可增加分割与站位不确定性，不能凭融合推断全部结节阳性。 |
| 坏死/不均匀 | 属可疑线索，需记录期相和测量规则；结核等感染也可坏死。 |
| 钙化/脂肪门 | 有助于鉴别背景，但不是单一排除或确认转移的规则。 |
| 密度/强化 | 仅在 HU 与序列可靠时定量；增强剂、时相、重建和部分容积均影响值。 |

大小工作流程依据：[NICE NG122，Diagnosis and staging，1.2.19–1.2.21](https://www.nice.org.uk/guidance/ng122/chapter/Diagnosis-and-staging)。此处仅借用其大小筛查概念，不把旧版分期背景或治疗路径直接移入本技能。

病理大小研究显示良性与转移结节大小有重叠，但该研究为离体形态计量，不能把其直径直接改成在体 CT 短径阈值。[Prenzel 等，Chest 2003](https://pubmed.ncbi.nlm.nih.gov/12576367/)

炭末沉着与恶性结节 CT 对照研究也存在形态重叠，且恶性组混合癌种；坏死等表现受结核流行背景影响。本技能据此建议纳入反应性/感染、肉芽肿、炭末等困难鉴别样本，而不生成通用判别公式。[Kirchner 等，2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4463312/)

## 三、N 分期与标签层级

肺癌 TNM-9 中，N1 为同侧支气管旁/肺门/肺内区域，N2 为同侧纵隔和/或隆突下，N3 涉及对侧纵隔/肺门，或任一侧斜角肌/锁骨上区域。N2a 与 N2b 按单个或多个 N2 **站**区分，不能把同站多枚阳性误算为多站。需保存原发灶侧别与站位；影像或穿刺支持的临床分期、切除标本的 pN、治疗后的 ypN 分开记录。[IASLC N 描述符原始研究，Huang 等](https://pmc.ncbi.nlm.nih.gov/articles/PMC12323887/)

逐结模型要求逐结对应；逐站病理不能无配对地赋给每枚结节。充分取样的阴性、取样不足和未取样分别记录，不能因同患者另一站阴性而把其余目标全部标阴性。

2026 年 ERS/ESGE/ESTS 指南强调适应证范围内的系统性内镜超声分期，并已更新阴性系统性检查后的处理建议。本技能仅用其提醒“检查范围与充分性影响参考标准”；不把 2014 版管理路径固定为将来的自动决策。[2026 指南](https://doi.org/10.1183/13993003.00097-2026)
