# CT 训练与研究协议

本文件规定读片教学与研究数据的工作流程。以下是本技能的项目设计建议；参数须依据实际资料预设，不代表已经验证的模型。

## 1. 先区分训练目标

| 目标 | 输入和监督信号 | 评价单位 |
|---|---|---|
| 分站/定位训练 | 连续 CT、解剖标志、专家站位与理由 | 结节/站位；另报边界争议 |
| 逐结良恶性/转移分类 | 淋巴结 ROI；能逐结对应的病理或取样 | 结节；统计须考虑患者聚类 |
| 逐站转移分类 | 站内影像与该站病理 | 站；不把站级阳性分摊给每枚结节 |
| 患者级隐匿转移预测 | 原发瘤及/或淋巴结特征；患者最终 N 状态 | 患者；不声称找出了哪枚阳性结节 |
| 疗效/变化分析 | 配对时间点、同一结节跟踪、治疗信息 | 预设患者或病灶终点，避免时序泄漏 |

NSCLC、SCLC、食管癌/其他癌种和淋巴瘤分开建任务。是否转移、是否恶性和是否淋巴瘤并非同一个标签。

## 2. 人工读片训练

1. 从胸廓入口开始，沿气管、大血管和肺门连续滚动；每例输出站位、依据和置信度。
2. 在隐藏诊断/病理的条件下，先做定位，再填写形态表。短径以毫米记录，保存测量平面，避免把体素轴长当成临床轴位短径。
3. 加入容易混淆的血管断面、食管/奇静脉、正常小结节、肉芽肿或钙化结节作为练习；具体病例须来自有使用权限的数据。
4. 专家反馈分别指出“结构认错、站位错、边界不清、测量错、恶性推断过度”，不要只给总分。
5. 对 2/4 组、4L/5、5/6、4R/10R、4L/10L、3P/8、7/8 安排相邻层面和 MPR 对照。资料未完整展示的边界不能凭记忆补齐。

建议保留基线、复训和未见病例测评；这里不预设统一合格分数。分站准确率、读者一致性和漏结率按已裁决参考集评估，争议病例单独报告。

## 3. 病例与标签清单

每例至少记录去标识 patient ID、扫描 ID/日期偏移、癌种、治疗状态、原发灶侧别、纳入来源与失败原因。每个 node ID 关联下列信息：

- 序列 UID 的去标识映射、原始层面位置、三维轮廓和站位。
- 参考标准的日期与原文位置、是否逐枚或逐站配对、是否充分取样、裁决人。
- `positive / negative / indeterminate / unverified` 四类状态；不把后两类并入阴性。
- 标签时间与 CT 时间之间的间隔，以及间隔内治疗/感染等可能改变目标的事件。

未检出的微转移可形成“患者级阳性、影像上无可分割阳性结节”的病例；保留患者标签，不制造结节 ROI。仅凭影像报告得到的是影像/弱标签，不能用作病理金标准。

## 4. 图像与轮廓

核对 DICOM 的 PixelSpacing、层间几何、方向和强度变换；转换后保留 HU 和空间单位。扫描厂家、kVp、剂量、层厚/间距、重建核、增强剂和采集时相应进入批次记录。含造影剂与平扫的 HU 分布不直接混合解释。

预先决定二维最大截面还是三维全结节；三维可行时优先记录完整体积。轮廓应贴合结节本身，排除误并入的血管/食管；坏死、钙化是否包含须统一。若研究结节周围组织，保存独立掩膜，使用物理毫米膨胀并固定裁剪规则，说明如何处理肺、气道、大血管和邻近结节。

做盲法重复分割和扰动分析，记录读者间/读者内一致性。ICC 的模型、阈值及其选择理由须写清；本技能不把 0.75、0.80 或其他数值规定为通用门槛。

## 5. 特征提取计划

在研究协议中冻结：软件/依赖版本与配置哈希、体素间距、图像/掩膜插值、强度范围、固定 bin width 或 bin count、2D/3D 与纹理方向/距离聚合、启用的滤波器及尺度、原始与派生特征名。实施时读取对应软件版本文档；不直接复制网页 `latest` 的默认值。

先用 IBSI 参考对象验证计算，再在本队列检查小结节、层厚、噪声、重建核和轮廓扰动的稳定性。记录异常值、常数特征、空 ROI 和提取失败。尺寸和体积可能主导某些特征，必须比较“尺寸基线”并进行相应敏感性分析。[IBSI](https://theibsi.github.io/)

软件层面的重采样、离散化、滤波和掩膜校验配置需完整留存。PyRadiomics 可作为实现选择之一；对其定义与 IBSI 不一致的条目逐项注明。[PyRadiomics 配置](https://pyradiomics.readthedocs.io/en/latest/customization.html)

## 6. 划分与训练

采用患者级分组划分；同一患者跨结节、随访、相位和中心副本保持同组。独立中心测试集冻结到最终一次评价。只存在单中心内部留出时，明确称内部测试。[GroupKFold 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html)

把缺失处理、缩放、特征筛选、类别重平衡、批次校正和调参放入训练折内。数据驱动的稳健性筛选同样不得窥视测试结局。ComBat 等方法不能通过合并训练/测试并使用测试标签拟合来“提升泛化”；新中心的转换是否可用须有预设可部署方案。[数据泄漏与 Pipeline](https://scikit-learn.org/stable/common_pitfalls.html)

小样本先用可解释、复杂度受控的模型与基线比较，不因特征多就默认深度模型更好。结节数量不能冒充独立患者数量。报告学习曲线/样本量依据；单一固定的特征数对样本数比例不能替代风险评估。

## 7. 评价与交付

- 比较尺寸/常规 CT 基线、纯组学、融合模型；分别说明是否用了 PET、原发瘤或临床信息。
- 报 AUC 与置信区间、锁定阈值下的敏感度/特异度及预测值、校准；按实际用途考虑决策曲线。预测值受患病率影响，不能直接迁移。
- 多结节资料按患者聚类 bootstrap 或适当相关性模型估计区间；未见中心/扫描协议/小结节亚组单独审查。
- 保存配置、版本、模型及阈值、划分清单哈希、失败日志、轮廓质控和模型适用范围。SHAP 等解释模型关联，不证明组织学机制或因果关系。

论文与报告可按 CLEAR 和 TRIPOD+AI 核对透明性；符合报告清单不等于模型已获临床验证。[CLEAR](https://doi.org/10.1186/s13244-023-01415-8)、[TRIPOD+AI](https://doi.org/10.1136/bmj-2023-078378)

## 8. 进入定量训练前的停止条件

缺少可信强度/几何、掩膜错位、标签层级不一致、患者跨分区、未知期相混入且无法溯源，或测试集已经参与模型选择时，先修复数据和设计。无法修复的资料仅用于说明性教学或单独的探索性分析，明确其限制。
