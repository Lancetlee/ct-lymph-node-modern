# 从旧 TensorFlow 项目迁移

本项目依据用户提供的 `ct_mediastinal_structures_segmentation-master.zip` 研究流程进行重构。原仓库使用 TensorFlow 1.14 及旧依赖，新执行层使用 PyTorch，分别处理设备、影像几何、滑窗推理、候选结节和放射组学。原始代码及其 BSD 2-Clause 许可来源须保留。

## 能力与权重分别迁移

原 `src/fit.py::fit()` 是加载已有模型做推理的函数，名称并不表示它能训练新模型。源码压缩包本身没有 `resources/models` 中的 H5/检查点和每个模型的预处理配置；旧 `setup.py` 会从外部下载这些资源。

新架构的检查点必须与其结构和预处理配置相符。**旧 H5 权重不能改扩展名后交给 PyTorch，也不能把新网络的随机初始化称为原论文模型。** 只有同时完成层映射、权重变换、预处理匹配、推理输出对照和独立数据评价，才能提出“忠实迁移旧模型”或“保持原精度”的结论。当前未以真实旧权重完成这项证明。

新项目的合成演示或初始化检查点仅用于验证软件路径。处理真实病例应使用经过训练、来源明确、配置匹配的检查点；软件拒绝把演示权重当作已训练模型，是预期行为。

## 原实现中确认的问题与本次处理原则

| 原文件/逻辑 | 风险 | 新流程原则 |
|---|---|---|
| `pre_processing.py` 使用 `extension != 'nii' or extension != 'nii.gz'` | 条件恒真，NIfTI 也进入转换路径 | 按明确输入格式读取，读写分离；不得写回原 CT |
| `io.py` 用 `split('.')[0]` 拼输出路径 | 含点路径可能截断，输出也可能与输入相同 | 使用路径对象与独立输出目录；检查输入/输出不重合 |
| `run_pre_processing_guided()` 用先验返回值覆盖原 CT 几何变量 | 重建可能参考错误的 affine/形状 | CT、掩膜与网络输入分别持有几何；显式对齐后才组合 |
| 肺掩膜单独重采样后直接按 bbox 裁剪 CT | 同 spacing 不保证同物理网格 | 核对 shape、spacing、方向、origin/affine；需要重采样时显式处理 |
| ensemble 创建独立 runtime 却传入另一实例，且固定读概率文件名 | 阈值模式与文件名不匹配 | 新推理不依赖这些旧中间文件约定；融合规则写入报告 |
| 旧模型预处理对强度裁剪、归一化和缩放 | 网络输入不再是原始 HU | 原始 CT 保留；放射组学只使用可信原始强度和复核轮廓 |
| 类别分割输出被误解成逐枚结节或转移概率 | 病理监督和实例配对混乱 | 分割分数、候选 component、人工站位、病理标签独立存储 |

这是以新实现规避旧路径的重构，不等于对旧论文结果完成复现。

依赖迁移也要分别验收：PyTorch/MPS 分割成功不表示可选 PyRadiomics 已安装。固定的 PyRadiomics 3.0.1 缺少 Apple arm64 与现代 Python wheel，可能需要独立 CPU 提取环境及源码构建；详见 [Apple 环境说明](APPLE_SILICON.md)。保留 Python、包版本和构建记录，不能靠更改特征名称来冒充相同计算。

## 与已有数据的对接

- NIfTI：保留原体素强度和 affine。四维资料不能任意取第一个体积后视为同一个胸部 CT；先明确序列及时间点。
- DICOM：按唯一序列读取，不把一个目录里的多序列拼在一起；多序列目录显式传 `--series-uid`。当前读取器支持至少两层、规则正交网格的 classic 单帧 CT，并核对源切片位置、方向、间距及 FrameOfReferenceUID。Enhanced/多帧 CT、不等层距或机架倾斜等输入会被拒绝，应先通过经过验证的外部转换保留 HU/几何后使用 NIfTI，不能忽略警告后强行拼接。确认增强期相、方向、层间几何和 HU 变换，再写研究清单。
- 原肺掩膜/解剖先验：不直接按数组索引叠加。旧模型的 APG 先验规则与新架构不同；没有支持这种输入的已训练检查点时，不宣称沿用了旧 APG 能力。
- 原概率图：它是逐体素结构分数。旧默认的 0.4 是分割阈值，不是“40% 转移风险”。阈值或融合规则改变后要重新评价分割性能。
- 原分站/病理资料：保留来源与可对应层级；站级阳性不能传播成每个候选结节阳性。

## 建议迁移次序

先用合成资料确认输入保护与几何往返，再以同一可信 CT 和掩膜验证特征导出。接着使用已训练现代检查点评价分割；需要保留旧模型时，再把旧模型权重移植作为独立、可量化的工作包。不要用设备测速结果代替模型精度证据。
